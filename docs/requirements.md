# Calendar Hub 要件

予定をひとつにまとめる、個人と身内向けのカレンダー。Orbit とは別アプリで、連携は API 経由で疎結合にする。

## 利用者

| 主体 | できること |
| --- | --- |
| 本人（Google ログイン） | 自分の予定の作成・閲覧・編集・削除。グループ・招待の管理 |
| 友達・グループのメンバー（Google ログイン） | 共有された予定を、共有された粒度（詳細 / 空き・埋まりのみ）で閲覧。招待への回答 |
| 未登録ゲスト | 期限付き招待リンクから、その予定だけを閲覧・回答（後続） |
| AI（API キー） | キー所有者の権限の範囲内で読み取り・予定作成・空き時間検索。既定 scope は read |

## 時刻の扱い

- 終日予定は日付で持つ。`start_date` 〜 `end_date`、終了日は含まない（排他）。1日だけなら `end_date = start_date + 1日`。
- 時刻付き予定は UTC の時刻（`start_at` / `end_at`、終了は排他）と、作成時の IANA タイムゾーン（`timezone`）を持つ。
- 画面は端末のタイムゾーンで表示する。
- 繰り返し予定の作成・例外編集は MVP に含めない。Google 由来の繰り返し予定は、期間内のインスタンスとキャンセル例外を正しく表示する（Google 連携時）。

## 公開範囲

予定ごとに次のどれかを持つ。

- `private`：本人だけ
- `participants`：招待した参加者だけ
- `group`：指定グループのメンバー

さらに `busy_only` を指定すると、権限があっても「埋まり」だけを見せ、タイトルや詳細は返さない。権限外の予定の内容は、API のどの経路でも返さない。

## 画面

- 月・週・日のビュー。日・週は 24 時間のタイムラインで、重なる予定は横に並べる
- 予定の作成・編集・削除、タイトル検索、選択日の一覧
- スマホで操作できるレイアウト
- ログインしていなければ Google ログインへ誘導する

## MVP の受け入れ条件

1. Google でログインでき、ログアウトできる。許可したメールアドレスだけに制限できる
2. 自分の予定を月・週・日で表示し、作成・編集・削除できる（終日 / 時刻付き）
3. 他人の予定は API からも一切見えない（越境しない）ことをテストで確認している
4. 同じ予定を別タブで同時に編集したとき、後から保存した側が競合（409）になる
5. 旧 Calendar Hub（ChatGPT Sites 版）の予定を取り込める
6. AI 用 API キーを発行・失効でき、scope の範囲を超えた操作ができない
