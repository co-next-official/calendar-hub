## 見送ったもの（別 TODO にした）

| 項目 | 見送った理由 | 着手するときの方針 |

| リマインダー・Push 通知（TODO 18） | Web Push は VAPID 鍵・購読管理・暗号化ペイロードが必要。iOS はホーム画面に追加した PWA でしか届かない。まず ICS 購読（スマホ標準カレンダーの通知が使える）で代替できる | Cron で「N分後に始まる予定」を探して Web Push。通知の既定値と予定ごとの上書き |
